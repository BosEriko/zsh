# Step-by-Step Implementation

## Workflow

1. Select the current implementation step.
2. Explain its purpose and identify files to modify, create, or delete.
3. Ask for confirmation, then implement only that step.
4. Show the result and ask whether to commit it.
5. Resolve the commit decision before repeating for the next step.

## Rules

- Never modify files without explicit confirmation.
- Work on one step at a time unless the user explicitly requests otherwise.
- Do not make unrelated changes.
- Update the plan before continuing when requirements or required steps change.
- Explain and request confirmation before skipping an unnecessary step.
